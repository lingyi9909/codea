# Codea V1.1 Task 26 Integration & Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close Codea V1.1 by proving Tasks 22–25 work together on one exact checkpoint across functional, architecture, regression, packaging, Windows/macOS build, and offline-safety gates without adding product features.

**Architecture:** Task 26 adds no Runtime, TUI, Application, Agent, Skill, Plugin, or command behavior. It introduces only integration acceptance coverage and a dedicated CI aggregation workflow that reuses the accepted Task 22–25 tests plus existing V1 release/parity/packaging/offline tooling. Native offline and company-intranet evidence that CI cannot truthfully produce remains explicitly deferred/not_run rather than being inferred as PASS.

**Tech Stack:** Go 1.26.5, Bun 1.3.14, Python 3 + the repository's existing PyYAML dependency, GitHub Actions, PowerShell/Windows 2025 runner, macOS runner, OpenCode v1.18.11.

**Spec:** `docs/superpowers/specs/2026-08-26-codea-v1.1-agent-workspace-design.md` — Task 26 (§26.1–26.6) and project-wide engineering boundaries.

## Global Constraints

- No new product features in Task 26.
- Runtime baseline remains OpenCode `v1.18.11`.
- Architecture remains `TUI → Application → Codea-owned AgentRuntime → OpenCodeAdapter`.
- TUI/Application must not import OpenCode vendor DTOs.
- Professional Agent routing, command registry, trace model, security/DLP/Approval/Tool Policy remain Codea-owned.
- Windows support remains native Windows x64 with no WSL dependency.
- Release/runtime operation remains pure-intranet/offline; build-time CI downloads do not count as runtime dependencies.
- macOS release targets remain `darwin-arm64` and `darwin-x64`; Windows target remains `windows-x64`.
- Existing V1 evidence deferrals, including company-intranet G15, remain honest until real environment evidence exists.
- Task 26 may enter `awaiting_acceptance` only after its integrated Gate is fresh PASS; human acceptance remains separate.

- [ ] **Step 1: Add the acceptance contract test**

Use `unittest`; reuse PyYAML already required by `scripts/check-execution-state.sh` and add no new Python dependency:

```python
import json
import pathlib
import re
import unittest
import yaml

ROOT = pathlib.Path(__file__).resolve().parents[1]


class Task26AcceptanceContract(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.state = yaml.safe_load((ROOT / "docs/execution-state.yaml").read_text())
        cls.runtime = json.loads((ROOT / "runtime/version.json").read_text())
        cls.release = (ROOT / "packaging/config/release.yaml").read_text()
        cls.windows_install = (ROOT / "packaging/platform/windows/install.ps1").read_text()

    def test_tasks_22_through_25_are_human_accepted_before_task26(self):
        for task_id in ("22", "23", "24", "25"):
            task = self.state["tasks"][task_id]
            self.assertEqual(task["status"], "completed")
            self.assertEqual(task["verificationStatus"], "pass")
            self.assertEqual(task["taskGateStatus"], "pass")
            self.assertIs(task["humanAccepted"], True)
        self.assertEqual(str(self.state["current"]["task"]), "26")
        task26 = self.state["tasks"]["26"]
        self.assertIn(task26["status"], {"in_progress", "awaiting_acceptance"})
        self.assertIs(task26["humanAccepted"], False)

    def test_locked_runtime_and_release_targets_match_v11_contract(self):
        self.assertEqual(self.runtime["openCodeVersion"], "1.18.11")
        self.assertEqual(
            set(self.runtime["platforms"]),
            {"linux-x64", "darwin-arm64", "darwin-x64", "windows-x64"},
        )
        for platform, meta in self.runtime["platforms"].items():
            self.assertIn("v1.18.11", meta["url"], platform)
            self.assertTrue(meta["checksum"].startswith("sha256:"), platform)
        self.assertIn('openCodeVersion: "1.18.11"', self.release)
        for platform in ("darwin-arm64", "darwin-x64", "windows-x64"):
            self.assertIn(platform, self.release)

    def test_windows_release_path_has_no_wsl_runtime_dependency(self):
        self.assertIsNone(
            re.search(r"(?i)(^|[^a-z0-9_])wsl(?:\.exe)?([^a-z0-9_]|$)", self.windows_install)
        )


if __name__ == "__main__":
    unittest.main()
```
