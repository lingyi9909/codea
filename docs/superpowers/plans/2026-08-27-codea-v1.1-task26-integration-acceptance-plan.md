# Codea V1.1 Task 26 Integration & Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close Codea V1.1 by proving Tasks 22–25 work together on one exact checkpoint across functional, architecture, regression, packaging, Windows/macOS build, and offline-safety gates without adding product features.

**Architecture:** Task 26 adds no Runtime, TUI, Application, Agent, Skill, Plugin, or command behavior. It introduces only integration acceptance coverage and a dedicated CI aggregation workflow that reuses the already accepted Task 22–25 tests plus the existing V1 release/parity/packaging/offline tooling. Native offline and company-intranet evidence that CI cannot truthfully produce remains explicitly deferred/not_run rather than being inferred as PASS.

**Tech Stack:** Go 1.26.5, Bun 1.3.14, Python 3, GitHub Actions, PowerShell/Windows 2025 runner, macOS runner, existing OpenCode v1.18.11 release lock and Codea release tooling.

**Spec:** `docs/superpowers/specs/2026-08-26-codea-v1.1-agent-workspace-design.md` — Task 26 (§26.1–26.6) and project-wide engineering boundaries.

## Global Constraints

- No new product features in Task 26.
- Runtime baseline remains OpenCode `v1.18.11`.
- Architecture remains `TUI → Application → Codea-owned AgentRuntime → OpenCodeAdapter`.
- TUI/Application must not import OpenCode vendor DTOs.
- Professional Agent routing, command registry, trace model, security/DLP/Approval/Tool Policy remain Codea-owned.
- Windows support remains native Windows x64 with no WSL dependency.
- Release/runtime operation remains pure-intranet/offline; build-time CI downloads do not count as runtime dependencies.
- macOS release targets remain `darwin-arm64` and `darwin-x64`; Windows target remains `windows-x64`.
- Existing V1 release evidence deferrals (including company-intranet G15 where applicable) must remain honest and must not be upgraded to PASS without real environment evidence.
- Task 26 may enter `awaiting_acceptance` only after its integrated Gate is fresh PASS; human acceptance remains separate.

**Files:**
- Create: `tests/task26_v11_acceptance_test.py`
- Read-only inputs: `docs/execution-state.yaml`, `runtime/version.json`, `packaging/config/release.yaml`, `packaging/platform/windows/install.ps1`

**Interfaces:**
- Consumes: accepted Task 22–25 execution-state records and the locked runtime/release configuration.
- Produces: a deterministic static acceptance contract that fails closed before expensive integration jobs run.

- [ ] **Step 1: Add the acceptance contract test**

Create `tests/task26_v11_acceptance_test.py` with standard-library-only Python checks:

```python
import json
import pathlib
import re
import yaml

ROOT = pathlib.Path(__file__).resolve().parents[1]
STATE = yaml.safe_load((ROOT / "docs/execution-state.yaml").read_text())
RUNTIME = json.loads((ROOT / "runtime/version.json").read_text())
RELEASE = (ROOT / "packaging/config/release.yaml").read_text()
WINDOWS_INSTALL = (ROOT / "packaging/platform/windows/install.ps1").read_text()


def test_tasks_22_through_25_are_human_accepted_before_task26():
    for task_id in ("22", "23", "24", "25"):
        task = STATE["tasks"][task_id]
        assert task["status"] == "completed"
        assert task["verificationStatus"] == "pass"
        assert task["taskGateStatus"] == "pass"
        assert task["humanAccepted"] is True
    assert STATE["current"]["task"] == "26"
    assert STATE["tasks"]["26"]["status"] == "in_progress"
    assert STATE["tasks"]["26"]["humanAccepted"] is False


def test_locked_runtime_and_release_targets_match_v11_contract():
    assert RUNTIME["openCodeVersion"] == "1.18.11"
    assert set(RUNTIME["platforms"]) == {
        "linux-x64", "darwin-arm64", "darwin-x64", "windows-x64"
    }
    for platform, meta in RUNTIME["platforms"].items():
        assert "v1.18.11" in meta["url"], platform
        assert meta["checksum"].startswith("sha256:"), platform
    assert 'openCodeVersion: "1.18.11"' in RELEASE
    for platform in ("darwin-arm64", "darwin-x64", "windows-x64"):
        assert platform in RELEASE


def test_windows_release_path_has_no_wsl_runtime_dependency():
    assert re.search(r"(?i)(^|[^a-z0-9_])wsl(?:\.exe)?([^a-z0-9_]|$)", WINDOWS_INSTALL) is None
```
